# Sistema de Calificaciones con Vectores

## Descripción
Programa de consola que gestiona las calificaciones de cinco estudiantes usando vectores (listas) de Python: permite consultar, calcular estadísticas, buscar y modificar notas.

## Objetivo
Aplicar arreglos o vectores, índices, ciclos y condiciones para almacenar, consultar, modificar y procesar un conjunto de datos.

## Lenguaje utilizado
Python 3

## Funcionalidades
- Mostrar todas las calificaciones con su estado (aprobado o reprobado)
- Consultar una calificación por su posición (índice)
- Calcular el promedio
- Identificar la calificación más alta y la más baja
- Contar aprobados y reprobados (nota mínima: 70)
- Buscar un estudiante por nombre
- Modificar una calificación y mostrar el vector actualizado

## Instrucción básica para poder ejecutarlo:

3. Abre una terminal en la carpeta del proyecto y ejecuta en tu entorno de desarrollo o en Python web con el codigo:

```
python sistema_calificaciones.py
```
